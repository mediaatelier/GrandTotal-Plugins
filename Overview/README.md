## GrandTotal Overview Plugins

Installed in the Overview in the Plugins section, the plugins allow a html UI.

### Plugin Type

```xml
<key>types</key>
<array>
    <string>overview</string>
</array>
```
Find the API-Documentation at the bottom of the GrandTotal help or by opening this URL in your browser:
grandtotal://openReference

### How it works

Overview plugins render their own HTML UI inside the Overview. The `statistics` type places the plugin in the statistics section instead of the plugins section.

See [Plugin-Anatomy.md](../Plugin-Anatomy.md) for the `Info.plist` keys.
